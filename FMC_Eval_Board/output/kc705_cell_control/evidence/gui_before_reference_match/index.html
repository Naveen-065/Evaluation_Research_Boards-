Measurement notes

Rail values above are targets, not live voltage telemetry. ADC1 = READ/R9, ADC2 = RESET/R11, ADC3 = SET/R10. Current uses 56 Ω and nominal gain 7; offset and gain calibration are pending. Supply-current changes can include circuit overhead.

SET/RESET are bounded pulses, with no automatic threshold sweep. A completed command does not certify a changed resistance. After each job the read profile is restored and Caravel is held in reset.

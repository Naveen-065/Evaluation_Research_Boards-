PCB measurement notes

Read current is measured on SET / R10 / ADC3, using the active-minus-idle difference, 56 Ω shunt and nominal gain 7. Estimated conductance = ΔI / 0.5 V. Circuit overhead and uncalibrated gain affect this estimate.
